# **Data Science**
### *by Amelia*
## This repository contains all of the projects completed for data science class. So far, this includes the first problem set and the gradebook project. 
### The gradebook project is a helpful tool for students and teachers that allows them to easily store their grades (in a csv file). The methods enable the user to add, remove, or access grades, and also computes averages and GPAs. The program also has functionality that permits the user to visualize their grades through a bar graph. 
### The files used in the gradebook project is the gradebook python file, which contains the code for this program, the csv file used to store grades, and the text file containing the deliverables.
